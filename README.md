# To Doom (`v1.1.1`)

Персональна канбан-дошка задач для **Windows**, **планшета**, **iPhone** та **ШІ-агентів (MCP)** із миттєвою синхронізацією по Wi-Fi.

---

## Основні можливості (відповідно до відео)

1. **Канбан-дошка з 3 колонками (`До виконання`, `В роботі`, `Виконано`) та компактний режим рейки**:
   - Кольорові акценти колонок: синій (`До виконання`), помаранчевий (`В роботі`), зелений (`Виконано`).
   - Перетягування карток між колонками мишкою або дотиком.
   - Автоматичне встановлення `100%` при переміщенні в колонку `Виконано`.

2. **Інтерактивна смужка прогресу прямо на картці**:
   - Потягніть смужку прогресу на будь-якій картці вліво або вправо (мишкою чи пальцем на iPhone/планшеті), щоб змінити відсоток виконання з кроком `5%`.
   - Загальний прогрес проєкту зверху (`54% Прогрес проєкту · 1 з 5 виконано`) автоматично перераховується в реальному часі.

3. **Ховання вікна за правий край екрана Windows (`Tuck behind screen edge`)**:
   - Натисніть кнопку **`[|→]`** у правому верхньому куті вікна або глобальну комбінацію клавіш **`Alt + S`**.
   - Вікно сховається за правий край екрана, залишивши лише тонкий зелений язичок.
   - Клікніть по зеленому язичку біля краю екрана (або знову натисніть **`Alt + S`**), щоб миттєво повернути дошку.

4. **Проста синхронізація по Wi-Fi (iPhone, Планшет, інший ПК)**:
   - Натисніть **«Поділитися»** у рядку статусу.
   - Відскануйте **QR-код** камерою iPhone або планшета (у тій самій мережі Wi-Fi).
   - На iPhone у Safari натисніть **«Поділитися» → «На початковий екран»**, щоб встановити To Doom як повноцінний повноекранний додаток (PWA).
   - Всі дії (додавання задач, рух повзунка прогресу, переміщення між колонками та індикатори присутності `Ви` / `iPhone` / `Планшет`) синхронізуються миттєво через WebSocket.

5. **Підтримка ШІ-агентів через MCP (`Claude Code`, `Codex`, `Antigravity`, `Cursor`)**:
   - Вбудований сервер [`mcp-server.js`](./mcp-server.js) підтримує інструменти:
     - `list_tasks`
     - `create_task`
     - `update_task` (`task_id`, `column`, `progress`, `title`, `epic`, `assignee`)
     - `delete_task`

---

## Запуск

- **Десктопний додаток Windows**:
  - Подвійний клік на `Запустити без консолі.vbs` або `Запустити To Doom.bat`
  - Або через термінал: `npm start`
- **Тільки локальний веб-сервер**:
  - `npm run web` (відкриється на `http://localhost:3456`)
